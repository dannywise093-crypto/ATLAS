# NVIDIA Skills Catalog Snapshot

This directory contains the NVIDIA skill packages installed for ATLAS. Each
skill is in its own folder and has a `SKILL.md` entry point. The source of truth
is the official NVIDIA repository: https://github.com/NVIDIA/skills

ATLAS builds its runtime catalog with `npm run skills:build`. See
[`../README.md`](../README.md) for the installation snapshot, rebuild steps,
signature-verification guidance, and runtime safety boundaries.
